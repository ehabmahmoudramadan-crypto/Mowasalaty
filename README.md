# Mowasalaty (مواصلاتي)
Cairo public transport platform: passenger app, driver app, admin dashboard.

## Structure
- frontend/  React + Vite (routes: /app, /driver, /admin)
- backend/   Node.js + Express + SQLite (REST API + bus simulation)
- docs/      API, DB schema, demo script for the discussion

## Run
cd backend && npm install && npm run seed && npm start
cd frontend && npm install && npm run dev
